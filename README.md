# The Bronx 3 Lua Hub

A polished, modular Lua hub for The Bronx 3 with a dark interface, smooth animations, and organized tabs. The hub supports compatible Roblox Lua execution environments, handles errors gracefully, and uses modular code. It includes features like weapon modifications, custom crosshair styles, and a draggable main window with search functionality.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService or StarterGui.
3. Copy and paste the contents of the respective Lua files into the script.

## Usage

1. Run the MainHub.lua script to initialize the hub.
2. Use the tabs to navigate between different features.
3. Customize weapon modifications, view weapon information, and apply custom crosshair styles as needed.
